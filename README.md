# 프로젝트 이름

판다마켓 웹 페이지

## 프로젝트 소개

판다마켓 웹 페이지 만들기(현재까지 HTML, CSS를 이용하여 메인페이지, 로그인, 회원가입 페이지를 만들었음)

## 기술 스택

- HTML
- CSS
- GIT/GITHUB

## 주요 기능

- 로그인 / 회원가입 페이지
- 페이지 간 이동 (로고, 로그인/회원가입 text 클릭 시)
- SNS 링크 연결 (페이스북, 트위터, 유튜브, 인스타그램)
- 간편 로그인 연결 (구글, 카카오)

## 어려운 점

- CSS에서 부모-자식 간 요소들을 배치하는 것이 아직 많이 어렵다.
- CSS 용어들이 익숙하지 않아서(오른쪽 정렬 등등) 계속 중간중간에 찾아보게 된다.
- 반응형 CSS를 만드는 것을 아직 완전히 이해하지 못했다. 특히 @media.
- input에 눈 이미지를 넣기 요구사항을 하지 못했다. 어떻게 해야 할지 모르겠다.
- 여전히 CSS는 잘 모르겠다...

## 배운 점

- 첫 미션을 할 때는 HTML 전체 구조조차 구성하는 것이 버거웠다. 그러나 두 번째 미션할 때에는 HTML 전체 구조를 쉽게 구성할 수 있었다.
- CSS 작업을 하면서 필요한 CLASS를 추가하는 등 HTML 전체 구조를 중간중간 수정할 수 있게 되었다.
