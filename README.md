# 🐼 Panda Market - Sprint Mission 1

## 📌 프로젝트 소개

Panda Market은 따뜻한 중고거래 커뮤니티 플랫폼을 구현하는 프로젝트입니다.  
본 스프린트 미션에서는 **HTML과 CSS를 활용하여 로그인 및 회원가입 페이지 UI를 구현**하였습니다.

웹 페이지의 기본 구조 설계와 스타일링을 직접 구현하며  
프론트엔드 기초 역량을 다지는 것을 목표로 합니다.

---

## 🛠 기술 스택

- HTML5
- CSS3
- Flexbox
- Reset CSS
