## **🐼 판다마켓 (Pandamarket)**

중고 거래 플랫폼 제작 프로젝트

**프로젝트 소개**
판다마켓 프로젝트의 1, 2차 미션을 수행했습니다.
미션에서 요구된 페이지는 랜딩 페이지(index), 로그인 페이지, 회원가입 페이지 세 개로 구성되어있지만 랜딩페이지와 로그인 페이지만 완성하였고, 회원가입 페이지는 미완성하였습니다.
다음 미션 제출 때 함께 완성하여 제출하겠습니다.

사용기술은 다음과 같습니다.

- HTML
- CSS

1. 랜딩 페이지

- 심화 요구사항인 네비게이션 바 fixed 처리 및 해상도에 따라 상단의 로고와 로그인 버튼의 위치가 조절되도록 media 속성을 이용했습니다.

2. 로그인 페이지

- form태그를 이용해 이메일과 패스워드 항목을 필수 입력값으로 설정하였고, 해당 항목에 포커싱 될 경우 아웃라인이 보여지게끔 css처리 했습니다.

##

- 디렉토리 구성은 css 파일들이 들어가는 css 디렉토리, 각 이미지들이 페이지별 디렉토리로 분리된 img 폴더로 구성했습니다. 이미지 폴더 안에는 공통으로 쓰이는 이미지들(예. 로고)이 들어가는 common폴더, 그리고 각 페이지별로 사용되는 이미지를 담은 폴더들을 생성해 분리했습니다.
- 모든 링크 및 경로는 절대경로가 아닌 상대경로로 설정했습니다.

##

**미완성 사유 / 리뷰 받고 싶은 부분**

- css의 속성들, 특히 flex display에 대한 기초 지식이 부족했습니다. 각 항목 별로 어떤 속성을 적용해야 하는지 고민하는 데에 많은 시간을 소요한 것 같습니다.
- 표준 페이지를 작성하기 위해 각 태그 요소를 어떻게 설정해야 할지, 구조를 큰 틀부터 쪼개나가는 과정에서 생각이 많았습니다. 기존에 알고 있는 태그 및 css 속성을 사용하면 요구사항에 맞는 페이지를 구현하는 것이 어렵지는 않겠으나, 최대한 시맨틱 태그의 기초적인 규칙을 따르고 싶었고, 스프린트 교육을 통해 새로 배운 것들을 이용해 작업하고자 하는 욕심이 미완성의 결정적인 원인이 되었습니다. 이번 코드 리뷰를 통해 멘토님께 배운 지식으로 보완해야하는 부분은 보완하여 완성하고 싶은 욕심에 미완성인 상태로 제출하게 되었습니다.
- css 속성을 최대한 정리하고 싶었습니다. 공통적으로 사용되는 속성이나 설정 같은 것들을 분리해서 css가 중복으로 적용되지 않게 하는데에 많은 생각을 했습니다.
- 특정 기능들은 기초적인 js나 jquery를 통해 핸들링하는 것이 익숙해 css만으로 구현하는 작업에서 어려움이 있었습니다. 어느 범위까지가 css로 가능하고, 어느 범위까지가 js로 구현되어야하는지 분리하여 생각하는 것 또한 시간이 지체된 사유가 되었습니다.
- gap을 효율적으로 사용하는 방법에 대한 이해가 부족했습니다.
- 클래스명에 대한 규칙을 어떻게 가져가야 하는지도 멘토님의 조언을 받고 싶습니다.
