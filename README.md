### [스프린트 미션 1: 랜딩 페이지]

- [V] React 없이 순수 HTML/CSS로만 구현
- [V] PC 사이즈(1920px) 기준 디자인 가이드 준수
- [V] Netlify 배포 완료 및 루트 경로(`/`), Title("판다마켓") 설정
- [V] **GNB & Navigation**
  - [V] 로고 클릭 시 `/` 이동 및 '로그인' 클릭 시 `/login` 이동
  - [V] 스크롤 시 상단 고정(Fixed) 처리
- [V] **Responsive Layout (1920px 기준)**
  - [V] 1920px 이상: 배경색 확장 및 요소 중앙 정렬(Fixed Inner)
  - [ ] 1920px 미만: 양 끝 여백 200px 유지 및 가변 간격(Flexible) 구현
- [V] **Interactive UI**
  - [V] 클릭 가능 요소에 `cursor: pointer` 적용
  - [V] 푸터 SNS 아이콘 클릭 시 새 창으로 이동
